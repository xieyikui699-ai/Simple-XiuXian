# 变更流水（docs/changelog/）

一日一档：`YYYY-MM-DD.md`，文件名按日期排序即完整更新时间线（资源管理器直接可见）。

**约定（2026-09-10 定，方案 B）**

1. 每次更新（玩法/数值/口径/修复）收口时，在当日文件末尾追加一节 `## N. 标题` + 2–4 句摘要；当日文件不存在则新建（含同样的文件头指引）。
2. 同日多条按发生顺序连续编号；摘要面向「翻文件夹的人」——写清改了什么、为什么。实现细节留在仓库根 [CHANGELOG.md](../../CHANGELOG.md)（工程口径）与《[设计文档](../design/2026-09-06-小程序简化版设计.md)》各章节内嵌「变更记录」（设计口径），本流水不替代两者。
3. 条目落档后原则上不改写；补记历史条目需注明「补记」及依据。

历史自 2026-09-06（立项）起补录；2026-09-08 第 8 节为批次补记（四条无单独内嵌日期，随当日收口批次统一记录）。
